# 🌿 Shanti Portal | Mental Wellness Platform

A comprehensive, modern web application dedicated to mental health awareness, accessibility, and personal wellness tracking. **Shanti Portal** provides a serene digital space for users to access resources, track their emotional well-being, and connect with professional support systems.
---


## 🌟 Vision

The Shanti Portal aims to destigmatize mental health by providing an intuitive, "peace-first" interface where users feel safe and empowered to seek help and practice self-care.

---

## 🚀 Key Features

*   **Wellness Tracking:** Interactive mood logs and habit trackers to help users visualize their mental health journey.
*   **Resource Library:** A curated collection of articles, guided meditations, and mental health toolkits.
*   **Professional Directory:** Seamless integration for users to find and connect with mental health professionals and counseling services.
*   **Secure & Private:** Built with a focus on data privacy, ensuring that personal wellness logs remain confidential.
*   **Fluid UI/UX:** A calming aesthetic designed with soft color palettes and smooth transitions to reduce digital fatigue and anxiety.

---

## 🛠️ Tech Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | React.js, Tailwind CSS (Custom Wellness Theme) |
| **Backend** | Node.js / Django |
| **State Management** | Context API / Redux |
| **Database** | PostgreSQL / MongoDB |
| **Animation** | Framer Motion (for fluid, stress-free transitions) |

⚙️ Setup & Installation
Clone the Repository:

Bash
git clone [https://github.com/AdityaSadewale/Shanti-Portal-Mental-Wellness-Platform.git](https://github.com/AdityaSadewale/Shanti-Portal-Mental-Wellness-Platform.git)

Install Dependencies:

Bash
npm install
Environment Configuration:

Create a .env file in the root directory.

Define your DATABASE_URL and AUTH_SECRET.

Launch the Platform:

Bash
npm start
